Diese Website verwendet keine Cookies, kein Tracking und keine Analyse-Tools.

Die Seite wird über GitHub Pages (GitHub, Inc.) gehostet. Beim Besuch der Seite kann GitHub technische Daten wie Ihre IP-Adresse in Server-Logs verarbeiten. Details finden Sie in der <a href="https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement">Datenschutzerklärung von GitHub</a>.

Ein Demo-Video ist über YouTube im erweiterten Datenschutzmodus (youtube-nocookie.com) eingebunden. Bis Sie das Video starten, werden keine Daten an YouTube übertragen; beim Abspielen erhält YouTube (Google) technische Daten wie Ihre IP-Adresse. Details finden Sie in der <a href="https://policies.google.com/privacy">Datenschutzerklärung von Google</a>.

Wenn Sie uns per E-Mail oder über das Kontaktformular kontaktieren, verarbeiten wir die von Ihnen angegebenen Daten (etwa Name, E-Mail-Adresse und Nachricht) ausschließlich zur Bearbeitung Ihrer Anfrage. Nachrichten aus dem Kontaktformular werden über FormSubmit (formsubmit.co) an unser Postfach weitergeleitet.
